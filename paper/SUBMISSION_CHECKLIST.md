# Submission checklist

The scientific text, tables, figures, aggregate results, and bibliography are
complete in the journal-neutral manuscript. Before uploading to a specific
journal:

- replace the blinded author block with the confirmed author order and
  affiliations if the venue is not double-blind;
- add confirmed CRediT contributions, funding, acknowledgments, and competing
  interests (none are inferred in this repository);
- select the journal's class/style and apply its word, figure, and reference
  limits without changing the frozen values;
- confirm whether the technical illustration of M2238 is permitted under the
  selected venue's data-display policy;
- archive the tagged code release and record its DOI in Data and Code
  Availability.

Build with `make paper`; the reviewed journal-neutral PDF is `paper/main.pdf`.
