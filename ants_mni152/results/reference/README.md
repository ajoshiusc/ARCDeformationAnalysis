# Aggregate ANTs reference results

This directory contains de-identified aggregate tables regenerated from the
ARC inputs identified in `analysis_provenance.json`. Participant-level images,
transforms, predictions, and design matrices are intentionally excluded.

The tables are frozen outputs of `ants_mni152/run_analysis.py`; they are not
hand-entered manuscript values. See the separate ANTs supplemental material
for the complete pipeline-sensitivity results, including nonsignificant findings.
